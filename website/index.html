A free alternative to RescueTime · StayFree · Toggl Track - for people who would rather not hand their keystrokes to a SaaS.

The workflow

Four things it does, in the order you'd meet them.

  1. 01

    Track

    A silent daemon polls the foreground window on a configurable interval (default 5 s) via Win32 syscalls. Mouse movement, keyboard input and audio playback keep passive sessions - like a long video - counted. Per-app and per-site time land in a local SQLite database; browser titles are matched against 74 built-in categories such as Bilibili, YouTube, GitHub and ChatGPT.

    deepfocus gui
  2. 02

    Understand

    The desktop dashboard shows today's total, the last seven days, hourly rhythm, top apps and sites, recent sessions and limits hit. The statistics view covers 7 days, 30 days or a custom range. Optional experimental domain grouping folds every Bilibili video and subdomain into one site entry.

    deepfocus stats
  3. 03

    Protect

    Set a per-executable ceiling in minutes. At 80% the limit row warns, at 95% it turns red and a Windows toast interrupts you, with a Snooze action. Limits reset at local midnight. DeepFocus's own processes, the lock screen and Windows shell surfaces are always excluded; you can exclude any other executable and its rows disappear immediately.

    deepfocus limit chrome.exe 60
  4. 04

    Keep

    Your data leaves only when you say so. Export CSV or JSON from Settings (files land in Downloads), or open %APPDATA%\focusd\focusd.db in any SQLite browser. Turn on long-term history to keep every completed week in its own archive database, without dupes or gaps.

    Settings → Long-term history

The whole surface

One binary. Everything through the shell.

# desktop
deepfocus                    open the desktop app
deepfocus gui                open the GUI explicitly
deepfocus tui                terminal UI

# daily
deepfocus start              start background daemon
deepfocus stop               graceful shutdown
deepfocus status        (s)  today's top 5 apps
deepfocus stats         (st) full daily breakdown

# flow
deepfocus pause         (p)  pause tracking
deepfocus resume        (r)  resume tracking
deepfocus focus [min]        start Pomodoro (default 25)
deepfocus stop-timer         cancel Pomodoro
deepfocus limit <app> <min> daily cap for an executable

# housekeeping
deepfocus update             open the releases page (manual)
deepfocus retention set 14   keep 14 days of history
deepfocus autostart enable   launch daemon at login
deepfocus path enable        add to user PATH
deepfocus browser add zen.exe register a custom browser

How the pieces fit

The desktop and terminal clients call flush over local TCP before every report, so stats are always caught up on the in-flight session. deepfocus.exe provides the CLI and TUI against the same daemon and database.

The quiet part, loud

No network calls. Not even for updates.

DeepFocus does not contact GitHub, send telemetry, or check for updates in the background. Choosing deepfocus update simply opens the releases page in your browser; nothing is downloaded or installed by the app. Tracking, limits, Pomodoro, archives and export all stay on your machine.

  • MIT licensed. Read the source, ship it in a fork, resell it if you like.
  • No account. There is no server to sign up for.
  • No analytics. No page pings, no crash uploads, no "improve the product" checkbox.
  • You control updates. There is no updater. deepfocus update opens the releases page, and you decide whether to download anything.
FAQ

Common questions.

Does DeepFocus send my data anywhere?

No. Sessions are written to %APPDATA%\focusd\focusd.db. The app makes no network requests. There is no telemetry, account or cloud sync.

How is this different from RescueTime, StayFree, or Toggl Track?

DeepFocus has no cloud sync, no account, and no telemetry - all three competitors listed require an account and sync your data to their servers. DeepFocus writes tracking data only to a local SQLite database and never leaves the machine.

Which browsers can it group sites for?

Chrome, Firefox, Edge, Brave, Opera, Vivaldi, Waterfox, Arc, Safari, Whale, Yandex, Thorium, LibreWolf, Chromium, Floorp, Zen, and any custom executable you register with deepfocus browser add. Browser windows expose titles rather than full URLs, so site names are matched from titles and, optionally, grouped by domain.

Does it run on macOS or Linux?

Not yet. The tracker uses Win32 syscalls directly (user32, kernel32, psapi). The code compiles on other platforms via build stubs, but the daemon refuses to run.

What happens to my data if I uninstall?

The installer leaves %APPDATA%\focusd\ in place so you can reinstall without losing history. Long-term archives live in %APPDATA%\focusd\archive\. Delete that directory manually if you want a clean slate.

How do updates work?

There is no auto-updater. deepfocus update opens the GitHub releases page in your browser; DeepFocus never downloads or runs an installer on its own. You choose the build and install it manually.

Does it support Chinese?

Yes. The desktop app ships with full Simplified Chinese and English text, follows your system language on first launch, and lets you switch at any time.
